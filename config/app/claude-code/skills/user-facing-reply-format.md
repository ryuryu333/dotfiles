---
name: user-facing-reply-format
description: ユーザーに表示される文章を書く前に読む。
---

- ターンの最後の回答は、次の四つの部分で、この順に構成する。
  1. Markdown のレベル 1 の見出し。結論の概要を書く。
  2. user に聞きたいこと。なければ省く。
  3. 具体的な話。
  4. 比較検討の記録。user は普段読まない。選んだ理由を後から確かめるために置く。比べた案がなければ省く。
- 短い回答でも見出しを付ける。
- 見出し以外の場所では、レベル 1 の見出しを使わない。
- 聞きたいことは、二つ目の部分以外に書かない。
