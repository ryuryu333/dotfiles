# 役割の境界に対する考え方

## 境界を捉える順序

1. 名前や周囲との関係から、その対象がどんな役割を持つかを考える。
2. その役割に照らして、何をすべきで何をしないかを切り分ける。
3. それを担うために何を持ち、何を知る必要があり、何を持たず、知らなくてよいかを考える。

## 検討の整合性

これらの検討には順序があるが、一方通行ではなく相互に関係する。後の検討で見つかる矛盾は、前の段階の解釈を問い直す契機になる。

ただし、矛盾の原因が自身の解釈にあるとは限らない。解釈の見直しでも整合しない場合は、対象について置かれた役割や前提そのものにも、不整合がある可能性を考える。
