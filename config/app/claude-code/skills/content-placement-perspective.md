# 記述の置き場所に対する考え方

## 1. 記述と置き場所の適合

記述の妥当性は、その内容が事実として正しいかどうかだけでは決まらない。置き場所が何を表すために存在するかに照らして、そこに記述する必然性があるかも重要である。

関連する情報であっても、その置き場所が表す対象に属するとは限らない。一方、その対象を表すために欠かせない情報がなければ、記述は十分ではない。

重要なのは、記述できることと、記述すべきことを区別することである。

## 2. 記述同士の関係

一つの記述が適切かどうかは、ほかの記述との関係によっても変わる。既存の定義から一意に導かれる内容を、独立した規則として重ねて定義する必要があるとは限らない。

同じ事項を複数の場所で定義すると、現時点では一致していても、変更によって不整合が生じる余地が増える。ほかの定義を参照することと、その内容を再び定義することは異なる。

参照によって結び付ける場合も、参照先が変わったときに、どの記述や判断に影響するかを考える。

重要なのは、個々の記述だけでなく、記述全体として意味が整合し、必要な内容が成立していることである。
