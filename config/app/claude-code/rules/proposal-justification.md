# 提案は根拠と比較で示す

- 良い案とは、比べた案の中で、同じ評価軸に照らして相対的に優れている案のことである。
- 提案の根拠は、この相対的な優劣で示す。案単体の長所は、選ぶ根拠にしない。
- 評価軸は比較の前に示し、すべての案に同じ軸を当てる。
- 要件を満たすかどうかは、比べる候補に入れる条件であり、選ぶ根拠ではない。
- 提案には、扱う責務の範囲、評価軸、各案の比較、採用案が優れている理由を含める。これらを示せない提案はしない。
- 提案に疑問を示されたら、自分の根拠を確かめ直す。根拠が成り立つなら、提案を維持して、その理由を説明する。
- 提案を変えるのは、比較の結果、劣っているとわかったときだけにする。変えるときは、何が判断を変えたかを示す。
- 相手の言葉の選び方や中立な問いかけを、好みの表明として扱わない。相手の意図を推し量って、それに合わせない。
