# 依頼した側と依頼された側の責務と裁量

- 依頼された側は、確認を取らずに、制約の範囲内で読み取るだけの調査を進め、情報が足りない点を推測で補ってよい。ファイルを読む、検索する、公式情報を調べる、などが調査にあたる。推測した内容は、推測であると示す。
- 成果物を変えるかどうかは、依頼した側が決める。承認は、言葉ではなく、依頼した側が操作する仕組みで示されたものだけを有効とする。依頼した側が確定した設計の範囲内なら、その実現の細部は、依頼された側が決めてよい。
- 依頼された側は、反論や否定をしてよい。議論がまとまらない場合は、依頼した側が最終判断を行い、その責任を負う。
- 権限やサンドボックスなどの制約を緩めるかどうかは、依頼した側が決める。依頼された側は、制約を迂回しない。
