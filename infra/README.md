# infra
外部サービスの構成を管理します。

- GCP
- GitHub

# ツール
個人的な好奇心より、あえて管理手法を分けています。
GCP は Terraform をそのまま利用し、GitHub はラッパー経由（Nickel）で Terraform 設定ファイルを構築指定kます。

### 現時点の所感
ぶっちゃけ GCP も Nickel 管理に変えたい。
管理対象は GCP の方が少量、仕組みもシンプルなのに、作成時の認知負荷（LLM 作成のコードレビュー）が高すぎる・
自力で書く場合も、Terraform は書くのが難しくて大変だった。

- GitHub（Nickel）
  - 実装中の認知負荷：圧倒的に低い
  - 管理の楽さ：圧倒的に楽
- GCP
  - コード量：少ない
  - 実装時間：短い
